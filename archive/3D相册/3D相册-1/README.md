# 3D 相册

纯 CSS 的 3D 旋转立方体相册：内外两层立方体，鼠标移入时六面沿法线向外推开。

## 运行

用浏览器直接打开 `3D相册-1/index.html` 即可，**无构建、无依赖、无 JS**。

## 文件

```
3D相册-1/
├── index.html          12 个 <img>（内外各 6 面）
├── css/index.css       旋转、六面定位、悬停展开
└── img/1.jpg ~ 6.jpg   6 张照片（400×600，长边 600）
```

## 实现要点

- **内外两层复用同一批图**：内层原本用 `7.jpg..12.jpg`，但那三对文件与外层
  `1.jpg..6.jpg` 的 SHA256 完全一致，是同一批照片的重复副本，已删除。
- **`perspective` 挂在 `.wrap` 而不是 `.cube`**：透视只对"子元素"生效，
  写在旋转体自己身上不会产生纵深，3D 旋转会退化成平面斜切。
- **图片用 `object-fit: cover`**：源图是 3:4.5 竖图，塞进正方形面会被压扁 34%。
  `cover` 按需裁切而非拉伸，竖构图照片不会被拉变形的脸。
- **尺寸走 CSS 变量**：`--size` 一处改动即可整体缩放，不必同步修改 12 条 `transform`。

## 已知取舍

- 图片长边压到 600px（`200px` 面尺寸下的 3×，DPR 2 时仍有余量）。若把 `--size`
  调到 300px 以上，建议重新导出更长的边。
- 仅鼠标悬停交互，触屏设备上表现为持续自转。
