# apps-web-design-system 设计说明

## 出发点：先量，再改

「好看」没法直接验收，所以先把能验的量化出来，再对着数字改。

写了两个工具（都在 `build/design-review/`，不入库）：

**`audit.js`** —— 读 `style.css` 的主题变量算 WCAG 对比度；解码 PNG 算色彩分布、
字号分布、边框/阴影/交互状态的计数。

**`probe.html` / `probe2.html`** —— 用 headless Chrome 的 `--dump-dom` 把
`getComputedStyle` 的结果吐出来 —— 用来区分「CSS 写了但没生效」和
「根本没写」。

**PNG 解码是自己写的**（zlib inflate + 反滤波），因为这个模型没有视觉输入，
读不了截图 —— 只能靠像素统计。

## 为什么改共用层而不是逐页改

47 个页面，模块 CSS 里 `var(--…)` 引用 85/55/36 处，写死色只有 6/4/0/3/1 处。
**颜色几乎全走令牌**，所以改 `web/style.css` 的令牌层，47 个页面一起受益。

改逐页 = 47 份重复的样式；改令牌 = 一处。

## 令牌体系

```
--sp-1..8    间距，4/8/12/16/20/24/32/40
--r-sm..xl   圆角，6/10/14/18 + full
--shadow-1..3 一层微浮 / 两层抬起 / 三层浮层
--ease --dur 动效曲线与时长
```

设计约束写在 `style.css` 头部，改之前先读：

1. 正文对比度必须过 AA（4.5:1），弱化文字也不能低于 4.5:1
2. 边框一律 1px
3. 可点的东西都要有 hover / focus-visible / transition
4. 圆角、间距、阴影只用上面三套刻度

## 关键决策

### 页面底比卡面深，而不是反过来

原来页面底 `#F7F8FA` 比卡面 `#FFFFFF` **浅**，差值只有 2% —— 加上 0.5px 边框，
卡片在 2x 屏上根本立不起来。

现在页面底 `#EEF2F7` 比卡面深，配 1px 边框 + `--shadow-1`，卡片有了层次。

### 品牌色深一档

`#0284C7` 配白字是 4.1:1 —— 差一点点到不了 AA。
`#0369A1` 是 5.93:1，过。

`constants.js` 的 5 个主色、分类色、优先级色、心情色全部同步到同一套色板
（`#0369A1` / `#4F46E5` / `#0F766E` / `#B45309` / `#BE185D` / `#DC2626` / `#059669`）。

**暗色主题用亮一档**（`#38BDF8`），否则深底深字。

### 主题类挂 body，不挂 #app-main

原来的写法：

```js
theme.applyThemeClass(page.rootElement || document.body, data)
```

`rootElement` 是 `#app-main`，而页头 `.app-head` 在它**外面** ——
切暗色时正文变黑、页头还是亮的。

改成无条件挂 `document.body`。一行改动，48 个页面的暗色模式一起修好。

### 色彩只给有意义的地方

不是把界面涂成彩色。彩色只出现在三处：

1. **模块入口卡片的顶部彩条** —— 五个模块各一色，是这一页唯一的彩色，
   但一眼就能分出模块
2. **优先级药丸** —— 高红 / 中琥珀 / 低绿，不用读字
3. **心情按钮** —— 1 红 → 5 绿，附带 `MOOD_LEVELS` 里本来就有、
   但从来没人渲染出来的 emoji

其余一律是中性色。饱和度从 1.5% 提到 3.4% —— 看着有生气，
但没有变成花花绿绿的仪表盘。

### 字体不引入外部字体

`-apple-system` → `system-ui` 打头，中文落到 PingFang SC / 微软雅黑。
系统字体启动快、不用下载、没有 FOUT。

## 测试：把能验的都钉住

「好看」测不了，但它背后的硬指标能测。`design-system.test.js` 28 条断言：

- 6 种文字 × 3 种底色 × 2 个主题 = 全部过 AA
- 品牌色对浅底过 AA；暗色主题的 `--brand` 必须与浅色不同
- 所有 CSS 里不再有 `0.5px`
- 有 `:focus-visible`
- 页面底与卡面的对比度 ≥ 1.08（卡片要立得起来）
- 正文 ≥ 15px；没有 < 11px 的字号
- `ui.js` 发出来的类都有样式接住
- `stat.tone-accent/ok/warn/bad` 有样式（之前是死类）

**验证过这些用例能抓到问题**：把 `--text-muted` 退回 `#94A3B8`、
把 `1px` 改回 `0.5px`，4 条用例立刻变红；恢复后全绿。

## 预览工具也顺手对齐

`web/preview.html` 是预览壳，有自己的一套深色配色。这次改成与应用共用层
同一套语言（石板蓝底 + 天蓝强调），不然应用变好看了、预览壳还是旧的，
对比起来割裂。

## 已知没解决的

- **那 3 个坏掉的详情页**（notes / snippets / interview）—— `render()` 是从
  健身页拷来的，读空的 `state.items`，空态写着「暂无健身」。
  与本次改动无关，独立问题。
- **没有响应式断点** —— `style.css` 里一个 `@media` 都没有（除了这次加的
  `prefers-reduced-motion` 和 `print`）。手机宽度下布局会挤。
  这是既有的技术选择，不在本次范围。
- **部分模块的专属构件还没逐个精修** —— 本次统一了共用层的令牌、卡片、
  药丸、统计块、表单、按钮；模块内部更细的构件（知识中心的题卡、
  游戏的棋盘等）只做到了边框与过渡层面。
